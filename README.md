# AMA Hub

Centrale portal voor drie applicaties gebruikt tijdens de BIUPAMA opleiding (militaire tropengeneeskunde).

## Apps

| App | Beschrijving |
|-----|--------------|
| **Tropengeneeskunde** | Interactieve studiegids met klachtgestuurde diagnostiek, ziektebeelden en praktische informatie |
| **AMA Rooster** | Upload Excel rooster → bekijk als kalender → exporteer naar iCal |
| **SNAAK Command Center** | Militaire quotes game met battle mode, quiz en ranking systeem |

## Gebruik

Open `index.html` in je browser of bezoek de [live versie](https://arjansammani.github.io/ama-hub/).

## Lokaal draaien

```bash
# Direct openen
open index.html

# Of met lokale server
python3 -m http.server 8000
```

Geen installatie of build process nodig.

## Technologie

Pure HTML/CSS/JavaScript - geen frameworks, geen backend.
